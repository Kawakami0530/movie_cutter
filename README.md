# 動画分割ツール（試作版）

Android ChromeでMP4を115秒ごとに分割する、ブラウザ内完結型Webアプリです。動画をサーバーに送信しません。

## 機能
- MP4を1ファイル選択
- FFmpeg.wasm（シングルスレッド）で再エンコードなしの分割
- 元ファイル名に `_001.mp4` などを付与
- 内部の日時メタデータを更新（取得不可なら元ファイル最終更新日時）
- 分割ファイルを個別に順次ダウンロード開始
- 進捗表示・日本語エラー表示・再実行

## 技術構成
HTML / CSS / JavaScript / Vite / FFmpeg.wasm / GitHub Pages。ビルド時にFFmpeg coreをローカル配置し、実行時に外部CDNを使用しません。

## ローカル起動
Node.js 22推奨。

```sh
npm install
npm run dev
```

表示されたローカルURLへアクセスしてください。Android実機でPCの開発サーバーへアクセスする場合はHTTPSやネットワーク設定に注意してください。

## GitHub Pages
1. GitHubに `video-splitter` リポジトリを作り、mainへpush。
2. Settings → Pages → Build and deployment → Sourceで **GitHub Actions** を選択。
3. `.github/workflows/pages.yml` がビルドして公開します。
4. `https://<アカウント名>.github.io/video-splitter/` で確認します。

## 既知の制約・未検証事項
- **Android ChromeでフルHD・10分動画を安定処理できるか未検証**。入力全体をWASM仮想ファイルシステムへコピーするため、大容量動画はメモリ不足になり得ます。1.5GBの暫定ガードを設けていますが、1.5GB以下でも失敗し得ます。
- キーフレーム依存のストリームコピーなので、分割境界が115秒からずれる場合があり、境界付近の重複・欠落や再生開始時の不具合が生じ得ます。厳密な無欠落分割は保証しません。
- 撮影日時はFFmpegログのメタデータから読みます。QuickTime日時タグを優先し、次にcreation_time、最後にFile.lastModifiedを使います。日時のないタグ・非標準形式は取得できない場合があります。
- 出力の日時タグをAndroidギャラリーが採用するかは機種・アプリ依存です。FFmpegが出力するMP4 atomの全日時を個別に検証・書換する実装ではありません。
- 分割開始日時は要求された115秒刻みを使用しており、**実際のキーフレームにずれた先頭時刻を測定していません**。日時に多少の誤差が出る可能性があります。
- Chromeの自動ダウンロード制限により、一部ファイルの保存がブロックされる場合があります。JavaScriptから実際の保存完了を検知できないため、進捗の「完了」はダウンロード開始処理完了を指します。Chromeのダウンロード一覧を必ず確認してください。
- 初期試作です。実機で30秒、2分、5分、10分の動画を段階的に検証してください。重要な元動画はバックアップして使用してください。
